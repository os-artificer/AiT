# v1.0.0

下面的名称是产品标题，不是当前二进制路径：

- 文档中的 `aissh` — 二进制 `aitssh`，插件命令 `ssh`
- 文档中的 `aihost` — 二进制 `aithost`，插件命令 `host`
- 文档中的 `aiimg` / `ailog` — 二进制 `aitimg` / `aitlog`，插件命令 `img` / `log`

这是 AiT 的首个发布版本。AiT 是面向日常运维的命令行工具箱，包含五个工具：`ait`、`aissh`、`aihost`、`aiimg` 与 `ailog`。`ait` 还带有内置 AI 助手。

### ait

- 【Added】单独运行 `ait` 会启动 AI 助手，按你的自然语言描述逐步执行运维任务。
- 【Added】助手会立即执行只读命令（例如 `ls`）。会改动文件的命令先征求确认；像 `rm -rf` 这类高危命令每次都会再问一次。
- 【Added】可以用 `ait agent connect user@host` 把助手指到远程服务器，它会经 SSH 在那台机器上工作。
- 【Added】可以用 `ait agent model list` 列出模型，开关云端提供商，并配置本地 Ollama 模型。AI 功能仍属实验性，默认开启，可在配置中关闭。
- 【Added】可以通过 `ait` 运行任意 AiT 工具，例如 `ait ssh user@host` 或 `ait log search error`。
- 【Added】`ait shell` 打开工具箱提示符，其中 `install`、`update` 与 `upgrade` 会从 GitHub Releases 下载官方工具。最省事的起步方式是 `go install github.com/os-artificer/AiT/cmd/ait@latest`，然后在 `ait shell` 里运行 `install`。

### aissh

- 【Added】`aissh` 用与 `ssh` 相同的方式连接服务器，并读取 `~/.ssh/config`。它也支持经跳板机连接（`-J`）。
- 【Added】远程提示符显示当前目录与 Git 分支，便于确认所在位置。
- 【Added】可以用 `--save` 保存连接，或用 `--alias` 起名。之后 `aissh session --list` 列出已保存会话，`aissh session --load` 会重连并恢复先前屏幕与工作目录。
- 【Added】带 `--tmux` 时，断开后远端程序仍会继续运行。
- 【Added】`aissh get` 与 `aissh put` 在本机与服务器之间复制文件。会话内的 `!ait get` 与 `!ait put` 不必新开连接，也可穿过多层 SSH。进度行显示复制进度，Ctrl+C 可取消。
- 【Added】会话内 `!ait local` 切到本机，`!ait remote` 切回远端。`!ait suspend` 保存会话以便之后恢复。
- 【Added】`aissh shell` 打开用于管理会话的本地提示符，也可运行自有脚本与普通系统命令。
- 【Added】`aissh config` 可创建、查看、编辑并检查配置文件。

### aihost

- 【Added】`aihost top` 显示本机实时仪表盘，含 CPU、内存、磁盘、网络与协议图，以及进程列表。
- 【Added】在进程列表中可按 `/` 搜索，按 Enter 查看详情与近期日志，按 `x` 在确认后停止进程。
- 【Added】`aihost snapshot`、`aihost cpu`、`aihost proc` 等命令可一次性打印相同信息（文本或 JSON）。`aihost` 支持 Linux、macOS 与 Windows。

### aiimg

- 【Added】`aiimg` 读取照片中保存的细节，例如相机、拍摄时间与地点，并把 GPS 坐标转成可读地名。
- 【Added】`aiimg set` 与 `aiimg clear` 可修改或清除 JPEG 上的这些字段。默认写入新副本（`*_aiimg.jpg`），原文件保持不动。

### ailog

- 【Added】`ailog` 用一条命令在 Linux、macOS 与 Windows 上查看与搜索系统日志。有系统自带日志工具时优先使用，否则直接读日志文件。
- 【Added】可按关键字、正则，或像 `error AND NOT timeout` 这样的组合表达式搜索；也可按时间限制结果、跟随新行，或输出 JSON。
